# Portfolio Website — Khaoula SOUMANE

This repository contains the source code for my personal portfolio website. It serves as a showcase of my work and background as a Data Engineer, as well as a practical project for refining my skills in HTML, CSS, and JavaScript.

## Project Overview

While my main focus as a Data Engineer is building big data pipelines and machine learning infrastructure, I created this website from scratch to practice core web development principles without relying on third-party frameworks.

The project highlights my professional experience at Air France-KLM, Nsayblik, and IRIT, along with my recent technical projects in data engineering and MLOps.

## Technical Focus Areas

HTML5
Building semantic document structures, implementing accessible metadata, and configuring meta tags for system color schemes.

CSS3
Designing a responsive layout using CSS Grid and Flexbox. Features include dynamic CSS variables for automatic light and dark mode adaptation, custom hover states, glassmorphism headers, and styled scrollbars.

JavaScript
Implementing clean DOM manipulation to handle responsive navigation toggles.

## Tech Stack and Design

The website is built with vanilla HTML, CSS, and JavaScript, supplemented by FontAwesome icons and Google Fonts (Poppins). It uses a warm neutral color palette consisting of beige, brown, dark grey, white, and black.

## Project Structure

index.html
Main site structure and content.

style.css
Styling, layout, CSS variables, and media queries.

scripts.js
Mobile menu toggle functionality.

Images/
Company logos, project previews, and profile assets.
